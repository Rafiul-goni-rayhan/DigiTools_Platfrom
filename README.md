DigiTools 🚀
Overview:
DigiTools is a modern web application for browsing and purchasing digital products, templates, and productivity tools.



Main Technology:
React.js  
Tailwind CSS, DaisyUI 
JavaScript (ES6+)  
React-Toastify (NPM Package)  
JSON (for product data) 
Key Features:

Browse digital products and pricing plans.

Functional and dynamic cart system (add/remove products).

3-step user onboarding and guideline section.

Fully responsive user interface across all devices.

Dependencies:

react, react-router-dom, tailwindcss, daisyui

How to Run Locally:

Clone the repository: git clone :https://github.com/Rafiul-goni-rayhan/DigiTools_Platfrom
Navigate to the project directory: cd digitools

Install the required dependencies: npm install

Start the development server: npm run dev
